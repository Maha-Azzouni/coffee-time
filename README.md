# ☕ Coffee Time Website
A simple and responsive coffee shop website where users can explore coffee and dessert items, add them to an order, and view their cart with total price.

## 🚀 Technologies Used
- HTML
- CSS
- JavaScript

## ✨ Features
- Browse coffee and dessert products
- Add items to the order (cart)
- View cart with selected items, quantities, and total price
- Clean and user-friendly interface
- Responsive design for different screen sizes

## 📁 Project Structure
- `index.html` – Home page
- `menu.html` – Products menu
- `order.html` – Order (cart) page
- `book.html` – Book page
- `about.html` – About the shop
- `our-story.html` – Our Story page (the shop story)
- `sign-in.html` – Sign In page
- `sign-up.html` – Sign Up page
- `assets/` – Images and styles
